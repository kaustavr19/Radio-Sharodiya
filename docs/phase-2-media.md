# Phase 2 media delivery

Phase 2 reuses the approved station artwork and the supplied dhak recording while keeping their source masters outside the public build.

## Responsive artwork

- Fourteen PNG masters are preserved in `assets/source/media-masters`.
- Each master produces mobile (768×1024), tablet (1024×768), and desktop (1536×1024) crops.
- Every size is delivered as AVIF with WebP fallback.
- Mobile crops use scene-specific focal points so radios, people, pandals and processions remain deliberately framed.
- Runtime scene requests are deduplicated by scene and viewport class.
- Low-data mode requests only the mobile still and disables backdrop blur.

The derivatives are generated by `scripts/build-media-assets.py`. It requires Python with Pillow AVIF/WebP support. The generated comparison data is stored in `reports/media-variant-report.json`.

## Atmosphere audio

- The 27:36, 320 kbps source remains in `assets/sound` and is no longer imported into the production bundle.
- The delivered file is a three-minute, 96 kbps loop with an eight-second circular crossfade.
- It remains opt-in, independently controlled, and excluded from service-worker audio/range caching.
- `scripts/build-atmosphere-loop.mjs` rebuilds it when `FFMPEG_PATH` points to an FFmpeg executable.

## Verified result

| Metric | Before Phase 2 | After Phase 2 |
|---|---:|---:|
| Production build | 92.91 MB | 8.25 MB |
| Delivered images | 29.60 MB | 6.05 MB |
| Largest image | 2.50 MB | 0.18 MB |
| Delivered atmosphere | 63.17 MB | 2.06 MB |

Both AVIF and WebP delivery sets are included in the build; an individual browser downloads only the matching format and viewport size for a scene.
